GERTRUDIS — ASISTENTE PERSONAL MVP v2

Incluye:
- Tareas con fecha límite, prioridad y comentarios.
- Vista de tareas como hoja plana (tabla) o tarjetas.
- Memoria de largo plazo, guardada únicamente con la orden especial:
  "Gertrudis, guardar en memoria de largo plazo: [información]"
- Preguntas sencillas sobre la información guardada.
- Entrada y respuesta por voz si el navegador lo admite.
- Almacenamiento local en el navegador.

Limitaciones importantes:
- No hay todavía IA generativa: la interpretación de voz y las preguntas son reglas básicas.
- La memoria se guarda únicamente en este navegador/dispositivo.
- No existe sincronización ni copia de seguridad automática.
- Evita guardar números completos de cuentas bancarias, contraseñas o PIN.
- Reconocimiento de voz suele requerir Chrome Android y HTTPS.
- Las notificaciones no son fiables con la app cerrada; eso requiere una etapa posterior.

Publicación gratuita sugerida:
- Crear cuenta en GitHub y usar GitHub Pages, o elegir un hosting estático HTTPS gratuito.
- Subir todos los archivos de esta carpeta conservando sus nombres.
- Abrir la URL HTTPS en Chrome Android y elegir "Añadir a pantalla de inicio".

Ejemplos de voz:
- "Agrega enviar propuesta para el viernes, prioridad alta"
- "Gertrudis, guardar en memoria de largo plazo: Juan vive en España y las reuniones deben ser por la mañana"
- "¿Cuándo debo reunirme con Juan?"
- "¿Cuál es mi banco?" (si previamente guardaste el dato)
- "Muéstrame mis tareas"
- "Completa enviar propuesta"
